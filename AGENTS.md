# dnstool — правила работы агента

## Общение
- Общаться с пользователем на русском.

## Релизы (после каждого успешного изменения)
- После каждого успешно завершённого изменения кода предлагать пользователю:
  1. закоммитить изменения и запушить в `main`;
  2. поднять версию (`AppVersion`), создать git-тег вида `v2.9.x`;
  3. собрать и опубликовать подписанный релиз через `tools/make-release.ps1`
     (приватный ключ: `~\.dnstool\release-key-private.xml`), чтобы клиенты
     могли обновиться на месте через «Проверить обновления».
- Не пушить и не публиковать релиз без явного согласия пользователя.
